# ГАСТРО КИНГ, демо доставки — правила для агентов

Общие правила работы — в пользовательских настройках агента. Здесь только особенности проекта.

- Что это: демо Telegram Mini App доставки. Один файл `index.html`, опубликован через
  GitHub Pages: https://alex-marfin.github.io/gastro-king-demo/ (собирается из ветки `main`,
  файл `.nojekyll` не удалять).
- Репозиторий публичный, и всё, что в нём лежит, видно в интернете, этот файл тоже.
  Материалы аудита и данные клиента сюда не попадают; в демо только вымышленные имена,
  телефоны, адреса и цены.
- Проверка правки: открыть `index.html` в браузере на ширине 390 px и на компьютере; после
  отправки в `main` убедиться, что опубликованная страница обновилась.
